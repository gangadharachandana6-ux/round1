# AI-First CRM HCP Module

## Tech Stack
- Frontend: React + Redux
- Backend: FastAPI
- AI Agent: LangGraph
- LLM: Groq (gemma2-9b-it)

## Features
- Log Interaction (Chat-based)
- AI Summary using LLM
- Edit Interaction
- Follow-up Suggestions
- HCP Insights
- Product Recommendations

## Run Project

### Backend
cd backend
uvicorn main:app --reload

### Frontend
cd frontend
npm start
